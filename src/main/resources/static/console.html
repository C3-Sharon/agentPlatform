系统状态 / System Status

Demo 前可先运行系统自检，快速查看模型、Skill、插件运行时、MCP、External MCP、Memory 和控制台入口状态。
PendingSkillCall 可配置 memory/redis 存储；Redis 模式用于追问状态 TTL 持久化。

模型管理 / Model Console

Skill 市场 / Skill Market

Skill 市场发现会聚合内置 Skill、插件 Skill、插件状态、运行时状态和调用统计。

插件市场 / Plugin Market

此处用于上传外部 Skill Jar 插件，不用于上传简历、图片等业务文件。This section uploads external Skill Jar plugins, not business files such as resumes or images.
如果上传失败提示 skillName already exists，说明同名插件可能已经安装。

简历优化 / Resume Optimize

该模块用于稳定演示简历优化业务流程：上传简历、读取岗位网页、同步/异步优化、查询任务状态。
上传简历后需要先解析文本，再调用简历优化。会话附件接口负责保存文件和绑定 conversation_resource；解析接口负责将文件内容写入 resume_file，供 resume_optimize 使用。
上传成功后，请从响应中的 resourceId 或 metadata.resumeFileId 复制 resumeFileId。

解析简历文字 / Parse Resume File

解析成功后会返回 textLength 和 preview；解析完成后再调用同步或异步简历优化。
读取成功后，请从响应中复制 jobPostingId。当前后端 DTO 字段名为 jobUrl。
异步接口会返回 taskId，请复制 taskId 到下方查询任务状态。

长期记忆 / Long-Term Memory
